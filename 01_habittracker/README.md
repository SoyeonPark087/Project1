# Habit Garden v2.0 — Habit Tracker MVP

PRD와 과제 평가표를 기준으로 만든 설치 없는 HTML/CSS/JavaScript 해빗트래커입니다.

## 실행

`index.html`을 브라우저에서 바로 열거나, 폴더에서 아래 명령으로 로컬 서버를 실행합니다.

```bash
python -m http.server 8000
```

그 다음 `http://localhost:8000`에 접속합니다.

## 평가 기준 대응 기능

- **6개 목적 화면**: 오늘 / 습관 추가 / 습관 관리 / 캘린더 / 통계 / 설정
- **추가**: 이름, 아이콘, 컬러, 반복 요일, 목표 횟수, 알림을 가진 Habit 생성
- **수정**: 선택한 Habit의 모든 주요 속성 수정
- **삭제**: Habit과 연결된 HabitLog를 확인 후 함께 삭제
- **검색**: 오늘 화면에서 이름·이모지 실시간 검색
- **계산**: 오늘 진행률, 월 달성률, 현재/최고 연속 기록, 총 완료, 최근 7일
- **상태변경**: 완료/미완료, 횟수, active/paused 상태 변경
- **화면 갱신**: 처리 직후 화면과 통계를 즉시 다시 렌더링
- **오류처리**: 필수값/범위 검증, 삭제/초기화 확인, 미저장 편집 경고
- **영속성**: 브라우저 localStorage

## v2.0 데이터 정확성 보강

Habit은 `statusHistory`를 보유합니다. 일시중지/재시작 시점을 이력으로 저장하여:

- 습관 생성일 이전 날짜를 미완료로 계산하지 않습니다.
- 일시중지 이후 날짜만 수행 대상에서 제외합니다.
- 일시중지해도 과거 기록은 캘린더/통계에서 유지됩니다.
- 재시작한 날짜부터 다시 수행 대상으로 계산합니다.

기존 `habitGardenDataV1` localStorage가 있으면 v2 형식으로 자동 마이그레이션합니다.

## UI 개선

첨부 레퍼런스의 가벼운 모바일 카드 스타일을 참고해 폭과 여백을 줄이고 밝은 컬러를 강화했습니다.

- 모바일 중심 520px 이하 앱 레이아웃
- 컬러별 Habit 카드
- 최근 4주 기록 미니 그리드
- 주간 날짜 스트립
- 얇은 검색창과 컴팩트 하단 탭
- 프리셋 + 직접 이모지 입력
- 프리셋 + 직접 컬러 선택
