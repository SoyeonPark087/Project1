# Habit Garden — Habit Tracker MVP

PRD 기반의 설치 없는 HTML/CSS/JavaScript 프로토타입입니다.

## 실행

가장 간단한 방법: `index.html`을 브라우저에서 엽니다.

로컬 서버를 사용하려면 이 폴더에서:

```bash
python -m http.server 8000
```

그리고 브라우저에서 `http://localhost:8000`을 엽니다.

## 구현 범위

- 오늘 화면: 오늘 예정 습관 조회, 완료/미완료 상태 변경, 진행률
- 습관 추가: 이름/아이콘/색상/요일/목표/알림 저장
- 습관 상세/관리: 선택 Habit 조회, 수정, 삭제, active/paused 상태 변경
- 캘린더: 월 이동, 날짜 선택, 날짜별 HabitLog 조회 및 상태 변경
- 통계: 이번 달 달성률, 현재/최고 연속 기록, 총 완료, 최근 7일 차트
- 설정: 전역 리마인더 설정, 테마, 전체 데이터 초기화
- 영속성: 브라우저 `localStorage`
- 디자인: 주황/베이지/노랑 기반 Warm & Playful UI

## 데이터

첫 실행 시 기능 확인을 위한 데모 습관 및 최근 기록이 생성됩니다. 설정 화면의 “모든 기록 초기화”로 비울 수 있습니다.


## 최근 수정
- 습관 상세/수정 화면 상단에 이전 화면으로 돌아가는 뒤로가기 버튼을 추가했습니다.
- 저장하지 않은 편집 내용이 있으면 뒤로가기 전에 확인합니다.
